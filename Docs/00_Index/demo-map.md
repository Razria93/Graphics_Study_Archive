# Demo Map

이 문서는 캡처와 영상 evidence의 계획, 위치, 공개 판단 연결을 안내한다.

## Demo 산출물 위치

| 항목 | 위치 | 책임 |
| --- | --- | --- |
| demo 우선순위 | `Docs/04_Demos` | Part별 최소/대표/선택 캡처 후보 |
| 캡처 파일 | `Docs/_assets/captures` | 검토된 이미지 evidence |
| 영상 파일 또는 링크 | `Docs/_assets/videos` 또는 외부 링크 | 검토된 영상 evidence |
| 공개 판단 | `Docs/06_Publication` | public 후보 여부와 제외 사유 |

## Demo 등급

| 등급 | 기준 | 처리 |
| --- | --- | --- |
| 최소 캡처 | 예제 실행 여부를 보여주는 기본 evidence | 모든 주요 Work Unit에 최소 1개 확보 |
| 대표 캡처 | 포트폴리오에서 시각적 임팩트가 있는 evidence | README, Issue, PR 후보로 연결 |
| 선택 캡처 | 보조 설명용 evidence | 시간이 남을 때 정리 |
| 제외 캡처 | 권리/출처/품질 문제가 있는 evidence | public 후보에서 제외 |

## 운영 기준

- 캡처는 검증 문서의 실행 상태와 연결한다.
- 강의 화면 캡처, 유료 자료, 출처 불명 asset은 public 후보로 두지 않는다.
- 게시 전 파일명, 출처, 라이선스, 민감 정보 포함 여부를 확인한다.
