# Captures

이 폴더는 검토된 screenshot evidence를 둔다.

## 기준

- build/run 상태가 `성공` 또는 `부분 성공`인 예제의 capture만 둔다.
- 파일명은 Part/Chapter, 예제 또는 Topic을 드러낸다.
- 강의 화면 캡처와 출처 불명 asset은 제외한다.
