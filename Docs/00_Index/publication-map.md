# Publication Map

이 문서는 private archive 문서와 public subset 후보를 구분하는 위치를 안내한다. 공개 판단 상태값과 기준은 `Docs/06_Policies/publication-policy.md`를 따른다.

## 정본 위치

| 항목 | 위치 | 책임 |
| --- | --- | --- |
| 공개 기준 | `Docs/06_Policies/publication-policy.md` | public 후보/제외 기준 |
| 후보 목록 | `Docs/05_Publication/candidate-list.md` | 공개 가능한 subset 후보 기록 |
| private-only | `Docs/05_Publication/private-only.md` | private archive에만 둘 항목 기록 |
| 제외 사유 | `Docs/05_Publication/excluded-material.md` | 제외 대상과 이유 기록 |
| redaction | `Docs/05_Publication/redaction-log.md` | 제거 또는 재작성 필요 항목 기록 |
| 공개 전 체크리스트 | `Docs/05_Publication/publication-checklist.md` | 게시 전 최종 점검 |
| 공개 전 검토 | `local/publication` | public subset 후보의 민감 정보와 공개 가능성 점검 |

## 운영 기준

- 이 문서는 public subset 상태판이 아니라 공개 판단 정본 위치를 안내하는 map이다.
- raw/reference repo에서 public으로 직접 옮기지 않는다.
- private archive 문서도 public으로 그대로 복사하지 않는다.
- public 후보는 직접 이해한 설명, 직접 만든 capture/result, 라이선스 확인 asset 중심으로 다시 선별한다.
- 법률 자문처럼 단정하지 않고 공개 전 점검 기준으로 기록한다.
