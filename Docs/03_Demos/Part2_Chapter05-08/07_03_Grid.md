# Chapter07 Step3 Grid Demo

## 목적

폭·높이와 5×3 분할 수로 XY plane의 vertex·normal·UV·index를 생성하고, 15개 cell을 30개 triangle으로 연결하는 procedural mesh 생성 과정을 확인한다.

## 책임 범위

- Grid sample, vertex attribute와 cell triangulation의 실제 구현 선택을 설명한다.
- 일반 생성 원리는 [Procedural Primitive Generation](../../01_Topics/ModelingAndGeometry/ProceduralPrimitiveGeneration.md)으로 위임한다.
- Build/run/capture 사실은 [Verification Index](../../02_Verification/Part2_Chapter05-08/verification-index.md)로 위임한다.

## 입력과 출력

| 구분 | 내용 |
| --- | --- |
| 생성 입력 | Width 2.0, height 1.7, slices 5, stacks 3 |
| Vertex | `(5 + 1) × (3 + 1) = 24`, XY position, `-Z` normal, UV |
| Cell | `5 × 3 = 15`, cell마다 triangle 2개 |
| Index | `15 × 6 = 90`, `DXGI_FORMAT_R16_UINT` |
| 기본 UI | `Wireframe=On`, `Use Texture=Off`, `Draw Normals=Off` |
| 출력 | 5×3 cell과 동일 방향 대각선을 가진 wireframe Grid |

## 구현 흐름

1. Width와 height를 slices와 stacks로 나눠 `dx`, `dy`를 구한다.
2. `(slices + 1) × (stacks + 1)` sample을 순회해 XY position을 만든다.
3. 모든 vertex에 `-Z` normal과 정규화된 UV를 기록한다.
4. 인접한 네 vertex index로 cell마다 triangle 두 개를 만든다.
5. Vertex/index 목록을 GPU buffer로 올린다.
6. `TRIANGLELIST`와 wireframe rasterizer state로 topology를 표시한다.

## 핵심 구현

### Grid vertex 생성

```cpp
// Pseudo C++: 분할 교차점마다 vertex attribute 생성
BuildGridVertices(width, height, slices, stacks)
{
    for (j = 0; j <= stacks; ++j)
    {
        for (i = 0; i <= slices; ++i)
        {
            AppendVertex(Position(i, j), NormalMinusZ, UV(i, j));
        }
    }
}
```

- [분할 간격과 Grid vertex 생성](../../../Part2_Chapter05-08/07_Modeling_Step3_Grid/GeometryGenerator.cpp#L213-L249)

### Cell triangulation

```cpp
// Pseudo C++: 네 corner를 일관된 winding의 triangle 두 개로 연결
BuildGridIndices(slices, stacks)
{
    for (cell : Cells(slices, stacks))
    {
        AppendTriangle(i0, i2, i3);
        AppendTriangle(i0, i3, i1);
    }
}
```

## 시각 결과

비스듬한 XY plane에서 가로 5개, 세로 3개의 cell과 각 cell을 두 triangle로 나누는 대각선을 확인한다. Wide와 compact resize, minimize/restore 뒤에도 Grid 비율과 viewport 정합이 유지된다.

## 구현 범위와 한계

- Grid는 `z=1`의 XY plane이며 XZ ground plane을 생성하지 않는다.
- 분할 수는 runtime UI가 아니라 초기 `MakeGrid()` 인자로 고정한다.
- 16-bit index 범위를 넘는 입력에 대한 guard는 구현하지 않는다.
- Cylinder, sphere, subdivision과 face normal 생성은 후속 단계 책임이다.
- Video는 정적 topology에 추가 정보를 주지 않아 제외한다.
