# Examples

이 폴더는 예제별 설명 문서의 정본 위치다. root의 `Part*_Chapter*` 코드 폴더와 `Portfolio_RayTracer`를 기준으로 예제 단위 README와 status를 관리한다.

## 책임

- 모든 예제는 최소 문서화 대상으로 둔다.
- 예제 문서는 해당 예제가 무엇을 보여주는지, 어떤 코드 위치를 보면 되는지, 어떤 Topic과 검증 문서에 연결되는지만 설명한다.
- 그래픽스 원리 자체의 긴 설명은 `Docs/02_Topics`로 분리한다.
- build/run/capture 상세 결과는 `Docs/03_Verification`과 `Docs/04_Demos`로 분리한다.
- 기존 `Docs/99_Legacy/PartDocs` 문서는 참고 자료이며 현재 정본이 아니다.

## 최소 문서화 기준

각 예제는 최소한 다음 항목을 가진다.

- 목적
- 관련 Topic
- 코드 위치
- build/run 상태
- capture 상태
- known issue
- public 후보 여부

## 작성 기준

- 평서형 현재형을 사용한다.
- 코드 확인 전 항목은 `미확인`으로 둔다.
- 강의 원문 표현이나 raw 메모를 그대로 옮기지 않는다.
- 상세 정책은 [Documentation Workflow Policy](../07_Policies/documentation-workflow-policy.md)를 따른다.
