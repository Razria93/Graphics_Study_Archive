# Reviews

이 폴더는 Work Unit 진행 중 `local/study-review/` 또는 PR review에서 승격한 재사용 가능한 판단 요약을 둔다.

## 책임

- raw/reference/current/origin 상세 조사 원문을 복사하지 않는다.
- 다음 작업자가 반복 조사하지 않아도 되는 결론만 기록한다.
- 공개 가능한 설명이 아니라 archive 작업 판단 기록으로 유지한다.
- 예제 README, Topic, Verification, Demo, Publication 문서의 정본을 대체하지 않는다.

## 포함 항목

- 승격한 설명 또는 capture/result의 판단 이유
- 제외 또는 보류한 자료의 반복 가능한 판단 기준
- 후속 Work Unit에서 다시 확인해야 할 known issue
- 사용자 검토에서 결정된 정책성 판단
- 다음 PR의 회귀 검사에 재사용할 actionable review feedback

## 제외 항목

- raw 문서 원문
- source comment inventory 전문
- 개인 메모, 절대 경로, 계정 또는 환경 정보
- 강의 원문 구조나 표현을 그대로 옮긴 내용
