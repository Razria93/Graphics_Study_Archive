# Workflow Map

이 문서는 Work Unit 진행 시 각 단계에서 참고할 위치와 저장할 위치를 요약한다.

## 빠른 흐름

```text
code 확인
-> legacy/raw reference 확인
-> local mini plan
-> 01_Examples
-> 02_Topics
-> 03_Verification
-> 04_Demos
-> 06_Publication
-> 05_WorkLogs
-> local GitHub draft
-> 00_Index 갱신
```

## 단계별 위치

| 단계 | 참고 위치 | 저장 위치 |
| --- | --- | --- |
| 코드 확인 | root `Part*_Chapter*`, `Portfolio_RayTracer` | `local/mini-plans` |
| 기존 문서 확인 | `Docs/99_Legacy/PartDocs`, `Docs/99_Legacy/ImportPhase` | `local/study-review` |
| 예제 설명 | code, local review | `Docs/01_Examples` |
| 개념 설명 | examples, code, reference | `Docs/02_Topics` |
| 검증 | solution, executable, assets | `Docs/03_Verification` |
| 데모 | capture 후보, 검증 결과 | `Docs/04_Demos`, `Docs/_assets` |
| 공개 판단 | examples, topics, demos, assets | `Docs/06_Publication` |
| 작업 기록 | 변경된 산출물 전체 | `Docs/05_WorkLogs` |
| GitHub draft | WorkLog, Verification, Demo | `local/github/draft` |
| 지도 갱신 | 전체 산출물 | `Docs/00_Index` |
