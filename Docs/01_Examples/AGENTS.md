# Examples Guidelines

## 적용 범위

이 규칙은 `Docs/01_Examples/` 아래 문서에 적용한다.

## 책임

- 예제별 README와 status는 예제 하나가 무엇을 보여주는지 설명한다.
- Topic 원리 설명, Verification 결과, Demo evidence, Publication 판단은 정본 위치로 링크한다.
- raw/reference 원문, source comment, GitHub draft, 개인 메모는 이 폴더에 두지 않는다.
- 코드 확인 전 항목은 `미확인`으로 둔다.

## 작성 단위

- Part/Chapter 폴더마다 `README.md`와 `example-index.md`를 둔다.
- 모든 예제는 `example-index.md`에 빠짐없이 기록한다.
- 대표 예제만 별도 README를 깊게 작성한다.
- asset/build output 폴더는 예제 목록과 분리한다.

## 문체

- 평서형 현재형을 사용한다.
- 존댓말, 대화체, 감상문체를 사용하지 않는다.
- technical keywords, folder names, API names는 영어를 유지한다.
