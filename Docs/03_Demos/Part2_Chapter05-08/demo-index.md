# Part2_Chapter05-08 Demo Index

이 문서는 `Part2_Chapter05-08`의 demo capture/result 후보와 capture/result 연결 상태를 기록한다.

## 범위

- Chapter05 bundle: Step1 Matrix(GLM) → Step2 Lights(GLM) → Step3 DirectXMath → Step4 Lights(SimpleMath)
- Chapter06 흐름: Step1 COM ownership에서 Step2 첫 graphics frame, Step3 Model·View·Projection, Step4 shader stage와 UV 분기, Step5 GPU texture sampling, Step5A textured point-light shading, Step6 Directional·Point·Spot 비교, Step7 panel·scene viewport 분리, Step8 window resize resource lifetime, Step9 Phong·Blinn-Phong specular 비교로 확장
- Chapter07 흐름: Step1 indexed triangle mesh와 wireframe rasterizer state, Step2 vertex normal line, Step3 procedural Grid, Step4 열린 Cylinder side surface, Step5 Sphere, Step6 triangle subdivision, Step7 face normal diagnostic line, Step8 SphereMapping, Step9 FBX model import로 확장
- Chapter08 흐름: Step1 rim lighting에서 cubemap, environment mapping, IBL, Fresnel, bloom과 Shadertoy로 확장
- 주요 demo 후보: pipeline, modeling, cubemap, IBL, bloom
- 비고: Chapter05 Step1·3과 Chapter06 Step1은 설명 중심 단계, Chapter05 Step2·4는 대응 visual, Chapter06 Step2는 첫 D3D11 pipeline visual, Step3는 projection 비교, Step4는 shader 분기, Step5는 texture 선택, Step5A는 texture와 point-light 결합, Step6는 Light type 비교, Step7은 viewport 분리, Step8은 window size 변화, Step9는 specular model 비교 visual로 유지
