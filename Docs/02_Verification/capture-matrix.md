## 갱신 기준

- capture는 build/run 성공 또는 부분 성공 상태와 연결한다.
- 강의 화면 캡처와 출처 불명 asset은 evidence 후보로 두지 않는다.
- public 후보 여부는 `Docs/05_Publication`에서 별도로 판단한다.
