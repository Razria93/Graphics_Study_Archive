# Legacy Workflow Notes

이 문서는 과거 `_repo/workflow` 구조의 역할을 설명하던 legacy 안내문이다. 현재 workflow의 기준 문서가 아니다.

## 현재 기준

- 최신 문서 라우팅은 `Docs/00_Index/`를 기준으로 한다.
- 최신 정책 정본은 `Docs/06_Policies/`를 기준으로 한다.
- troubleshooting과 템플릿은 `Docs/98_Tools/`를 기준으로 한다.
- 과거 import 기록은 `Docs/99_Legacy/ImportHistory/`를 기준으로 한다.
- 기존 Part 문서는 `Docs/99_Legacy/PartDocs/`에 보관한다.

## 사용 기준

이 문서는 과거 구조를 이해해야 할 때만 참고한다. 새 작업의 기준으로 사용하지 않는다.
