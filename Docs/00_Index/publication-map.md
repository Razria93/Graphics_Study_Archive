# Publication Map

이 문서는 private archive 문서와 public subset 후보를 구분하는 위치를 안내한다.

## 정본 위치

| 항목 | 위치 | 책임 |
| --- | --- | --- |
| 공개 기준 | `Docs/07_Policies/publication-policy.md` | public 후보/제외 기준 |
| 후보 목록 | `Docs/06_Publication` | 공개 가능한 subset 후보 기록 |
| 제외 사유 | `Docs/06_Publication` | 제외 대상과 이유 기록 |
| 게시 전 검토 | `local/publication`, `local/github/public` | 민감 정보와 문체 최종 점검 |
| 게시 후 요약 | `Docs/05_WorkLogs` | 게시된 Issue/PR/문서 요약 |

## 판단 상태

| 상태 | 의미 |
| --- | --- |
| `public 후보` | 직접 작성했고 공개 전 체크리스트 통과 가능성이 있음 |
| `private archive` | private repo에는 둘 수 있으나 public 후보는 아님 |
| `검토 필요` | 출처, 권리, 민감 정보, 표현 재작성 여부 확인 필요 |
| `제외` | public subset으로 옮기지 않음 |

## 운영 기준

- raw/reference repo에서 public으로 직접 옮기지 않는다.
- private archive 문서도 public으로 그대로 복사하지 않는다.
- public 후보는 직접 이해한 설명, 직접 만든 evidence, 라이선스 확인 asset 중심으로 다시 선별한다.
- 법률 자문처럼 단정하지 않고 공개 전 점검 기준으로 기록한다.
