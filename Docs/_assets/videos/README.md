# Videos

이 폴더는 검토된 video 또는 video link reference를 둔다.

## 기준

- 원본 영상 파일을 바로 추가하지 않고 크기와 공개 가능성을 먼저 검토한다.
- 조작, animation, simulation처럼 screenshot만으로 설명이 부족한 항목을 우선한다.
- 강의 영상, 강의 화면 녹화, 유료 자료 기반 영상은 제외한다.
