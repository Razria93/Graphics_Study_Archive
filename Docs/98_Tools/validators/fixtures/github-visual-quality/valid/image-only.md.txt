# Demo Visual Fixture

## 요약

정적 visual만 사용하는 Demo Issue fixture다.

## 핵심 목표

- 정적 result image를 Demo Issue visual로 사용한다.

## Demo Assets

| 구분 | 파일 | 설명 |
| --- | --- | --- |
| Input screenshot | 없음 | 별도 입력 screenshot을 사용하지 않음 |
| Result screenshot | 없음 | 단일 screenshot 대신 result image를 사용함 |
| Result image | fixture image | fixture static result |
| Video | 없음 | video attachment를 사용하지 않음 |

## 시각 정보

### Static result

Fixture는 static result image 하나를 대표 visual로 사용한다.

![Static result](https://github.com/example/repository/blob/1111111111111111111111111111111111111111/Docs/_assets/captures/example.png?raw=true)
