# Issue Bodies

이 폴더는 GitHub Issue body 후보를 둔다.

## 기본 원칙

Issue는 Work Unit 작업 추적을 중심으로 만든다. Topic, Demo, Verification Issue는 독립 추적 가치가 있을 때만 만든다.

| 유형 | 생성 기준 |
| --- | --- |
| Work Unit Issue | Work Unit 범위와 완료 조건을 추적해야 할 때 |
| Topic Issue | 여러 Chapter를 관통하는 개념 문서가 독립 작업일 때 |
| Verification Issue | build/run 실패, 환경 문제, 미확인 묶음이 별도 추적 대상일 때 |
| Demo Issue | screenshot, video, result image 제작이 별도 작업일 때 |

PR 자체를 위한 별도 Issue는 기본으로 만들지 않는다. PR 상태는 `Docs/04_WorkLogs/issue-pr-index.md`와 Plan Issue 댓글에서 추적한다.
