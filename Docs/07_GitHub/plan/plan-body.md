# Graphics Study Archive Progress Plan

## 요약

이 Issue는 Graphics Study Archive의 공개 가능한 상위 진행판이다. 상세 구현 기록은 Docs 정본과 WorkLog로 위임하고, 이 본문에는 운영 목표와 진행 단위만 유지한다.

## 목표

Progress Issue 1개, 누적 진행 댓글 1개, PR 마감 단위 plan comment, Chapter PR 본문 정본을 기준으로 진행 상태를 관리한다.

## Phase 범위

- Phase 1: 문서 구조와 GitHub 게시 workflow 정리
- Phase 2: Part1 정리
- Phase 3: Portfolio_RayTracer 연계
- Phase 4: Part2 정리
- Phase 5: Part3 정리
- Phase 6: Part4 정리
- Phase 7: 최종 검증과 Publication 후보 정리

## 완료 조건

- Progress 본문, 누적 진행 댓글, plan comment, Chapter PR의 책임 경계가 일치한다.
- 각 PR 마감 시 `plan-progress` 갱신과 plan comment 게시가 누락되지 않는다.
- 주요 검증과 제한 사항이 Verification, Demo, WorkLog 정본으로 연결된다.

## 기본 게시 객체

- Progress Issue 1개
- 누적 진행 댓글 1개
- PR 마감 단위 plan comment 여러 개
- Chapter 또는 작은 Chapter 묶음 단위 PR 여러 개

## 선택 Issue 생성 기준

- Progress와 PR만으로 추적하기 어려운 독립 작업
- 장기 논의가 필요한 정책/기술 판단
- 별도 승인 범위가 필요한 검증, demo, publication 판단
