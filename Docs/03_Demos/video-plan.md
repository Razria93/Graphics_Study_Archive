# Video Plan

이 문서는 video evidence 확보 계획을 기록한다.

## 파일 또는 링크 위치

- 검토된 video reference: `Docs/_assets/videos/` 또는 외부 링크
- raw video 후보: `local/`
- 게시 전 설명 초안: `local/github/draft`

## 우선 video 후보

| 범위 | 후보 | 보여줄 개념 | 상태 |
| --- | --- | --- | --- |

| Part3_Chapter10-13 | shadow quality 비교 | shadow mapping, PCF, PCSS | 후보 |
| Part4_Chapter14-20 | 대표 sample 실행 | advanced graphics 후보 | 미확인 |

## Video Checklist

| 항목 | 기준 |
| --- | --- |
| 길이 | 짧고 반복 시청 가능함 |
| 흐름 | 시작, 조작, 결과가 분명함 |
| 설명 | 화면 밖 설명은 README/PR 본문으로 분리함 |
| 권리 검토 | 강의 화면, 유료 자료, 출처 불명 asset이 아님 |
| 연결 문서 | Example, Topic, Verification 문서와 연결됨 |

## 갱신 기준

- 큰 영상 파일은 repo에 직접 추가하기 전에 저장 방식을 검토한다.
- public 공개 전에는 `Docs/05_Publication` 기준으로 다시 점검한다.
