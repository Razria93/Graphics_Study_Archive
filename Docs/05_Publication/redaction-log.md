# Redaction Log

이 문서는 public 후보로 옮기기 전에 제거하거나 재작성해야 할 항목을 기록한다. 민감한 원문은 이 문서에 직접 적지 않는다.

## 기록표

| ID | 대상 | 유형 | 조치 | 상태 | 비고 |
| --- | --- | --- | --- | --- | --- |
| RD-001 | public README 후보 | 강의 기반 표현 가능성 | 공개용 문장으로 재작성 | 예정 | 후보 확정 후 수행 |
| RD-002 | `02_Bloom` input/result | generated asset provenance | 생성 날짜, prompt 원문, provenance screenshot, 작업용 원본 확인 후 공개 문구 확정 | 진행 중 | Input APP1 metadata 제거와 decoded pixel 유지 확인. Result PNG metadata와 육안 검사는 통과. 생성 도구는 ChatGPT로 기록됐으나 나머지 provenance는 미확인 |
| RD-003 | WorkLog 요약 | local/GitHub draft 흔적 | 게시 전 문체와 민감 정보 제거 | 예정 | Issue/PR 작성 전 수행 |

## 유형

- 강의 원문 표현
- 유료 자료 또는 강의 화면 흔적
- 출처 불명 asset
- 계정 정보 또는 개인 정보
- 로컬 절대 경로
- 제출 대상별 기록
- draft 문구 또는 대화체

## 운영 기준

- 민감한 원문은 tracked Docs에 적지 않는다.
- 상세 검토 메모는 `local/publication`에 둔다.
- 완료된 redaction은 WorkLog에 요약만 남긴다.
