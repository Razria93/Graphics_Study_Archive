# Demo Visual Fixture

## 요약

본문에 standalone video attachment를 삽입한 invalid fixture다.

## 핵심 목표

- Standalone video attachment를 invalid case로 검출한다.

## Demo Assets

| 구분 | 파일 | 설명 |
| --- | --- | --- |
| Input screenshot | 없음 | 별도 입력 screenshot을 사용하지 않음 |
| Result screenshot | 없음 | 단일 screenshot 대신 result image를 사용함 |
| Result image | fixture image | fixture static result |
| Video | standalone attachment | invalid fixture가 검출해야 하는 attachment |
