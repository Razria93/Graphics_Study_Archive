# Policies

이 폴더는 문서화, 검증, demo, GitHub 운영, 공개 정책의 정본을 둔다.

## 책임

- 반복 적용되는 규칙을 한 위치에 모은다.
- 각 산출물 폴더 README에는 정책 원문을 반복하지 않는다.
- 정책 변경이 있으면 관련 Work Unit과 Index에 필요한 링크만 갱신한다.
