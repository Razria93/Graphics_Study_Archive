자료의 범위

교재·강의 기반 학습 예제의 실행 결과입니다. 예제 전체를 독자적으로 설계했다는 의미가 아니며, 영상에 표시된 프레임 수치는 통제된 성능 측정 결과로 사용하지 않습니다.

Codex는 이번 공개를 위해 기존 녹화 자료를 확인하고 오디오 제거·웹 재생용 인코딩·링크 연결을 수행했습니다. 원본 녹화 자료는 보존했습니다.

애니메이션은 끝부분만 잘랐으며, 연기·잔디 영상은 전체 구간을 유지했습니다. 세 영상 모두 화면 비율과 원래 재생 속도를 유지했습니다.
