# Policies

이 폴더는 Graphics Study Archive에 반복 적용되는 운영 정책의 정본 위치다. 산출물 본문은 `Docs/00_Index`부터 `Docs/06_Publication`에 두고, 정책 원문은 이 폴더에 둔다.

## 책임

- 문서 정본 위치, 작업 흐름, 검증, demo, publication, GitHub 운영 규칙을 정의한다.
- 각 산출물 폴더 README에는 정책 원문을 반복하지 않고 이 폴더로 링크한다.
- 정책 이름은 책임이 드러나도록 유지한다.
- 정책 변경 시 관련 Index, WorkLog, template 링크를 필요한 범위만 갱신한다.

## 운영 기준

- 평서형 현재형을 사용한다.
- 정책 문서는 이 폴더에만 둔다.
- 세부 작업 초안과 GitHub draft는 `local/`에 둔다.
- 과거 import 기록은 `Docs/99_Legacy`를 기준으로 참조한다.
- 구조 정리 작업 후에는 `structure-cleanup-roadmap.md`를 갱신한다.
