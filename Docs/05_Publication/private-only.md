# Private Only

이 문서는 private archive에는 둘 수 있으나 public subset 후보로 보지 않는 항목을 기록한다.

| 항목 | 이유 | 연결 위치 | 상태 |
| --- | --- | --- | --- |
| legacy import 기록 | raw/archive 구성 이력 추적용 | `Docs/99_Legacy` | private archive |
| Work Unit 내부 판단 메모 | 작업 흐름 추적용 | `Docs/04_WorkLogs`, `local/` | private archive |
| raw/reference 검토 메모 | 원문 표현과 민감 정보 포함 가능성 | `local/` | private archive |
| `Chapter07 Step5 Sphere ReferenceSolution` | 강의 reference 기반 비교 구현이며 UserSolution의 공개 근거를 보조하는 용도 | `Part2_Chapter05-08/07_Modeling_Step5_Sphere_ReferenceSolution`, `local/chapter07/step5/baseline/` | private comparison |

## 기준

- private-only는 삭제 대상이 아니다.
- public repo로 옮기려면 직접 이해한 공개용 설명으로 재작성한다.
- 민감 정보, 계정 정보, 절대 경로, 제출 대상별 기록은 tracked Docs로 승격하지 않는다.
- 미확인 build/run 상태는 private-only가 아니라 `candidate-list.md`의 검토 필요 항목으로 관리한다.
