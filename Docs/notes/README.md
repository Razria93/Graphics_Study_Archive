# Notes

예제별 note는 private portfolio archive 안에서 issue처럼 읽히는 짧은 문서로 작성합니다.

## 템플릿

```md
# Example Name

## 목표

## 시연 포인트

## 핵심 개념

## 구현 위치

## 공개 가능성

- 상태: private 전용 | public 후보 | 검토 필요 | 제외
- 근거:

## 관련 문서

## 정리한 내용

## 보강할 점
```

강의 원문 코드, 강의 자료 요약 전문, 문제/해설 전문, private-only 개인 메모는 note에 포함하지 않습니다. 공개 가능성 판단 기준은 [../public-readiness.md](../public-readiness.md)를 따릅니다.
