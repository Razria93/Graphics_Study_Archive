# Publication Guidelines

## 적용 범위

이 규칙은 `Docs/06_Publication/` 아래 문서에 적용한다.

## 책임

- public subset 후보와 제외 대상을 구분한다.
- 공개 전 redaction, 권리, 출처, 민감 정보 점검 기준을 기록한다.
- Example, Topic, Verification, Demo의 정본 문서로 링크한다.
- public repo 생성이나 GitHub 게시 작업은 사용자가 명시 요청한 경우에만 진행한다.
- raw/reference 원문, 강의 자료, 유료 자료, 개인 메모는 이 폴더에 두지 않는다.

## 작성 단위

- 후보 목록은 `candidate-list.md`에 둔다.
- private-only 항목은 `private-only.md`에 둔다.
- 제외 대상은 `excluded-material.md`에 둔다.
- 공개 전 제거/재작성 항목은 `redaction-log.md`에 둔다.
- 최종 점검 기준은 `publication-checklist.md`에 둔다.

## 문체

- 평서형 현재형을 사용한다.
- 존댓말, 대화체, 감상문체를 사용하지 않는다.
- 법률 자문처럼 단정하지 않고 점검 기준으로 표현한다.
- technical keywords, folder names, license names는 영어를 유지한다.
