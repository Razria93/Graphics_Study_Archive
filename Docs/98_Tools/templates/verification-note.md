## 작성 기준

- 내부 조사 항목은 local-only review에 둔다.
- 직접 확인하지 않은 build/run은 `미확인`으로 둔다.
- 문서화 이전에 직접 확인한 성공은 `성공`과 `과거 확인`을 함께 기록한다.
- 과거 성공 이후 다시 실행하지 않았으면 결과와 별도로 `재검증 필요`를 기록한다.
- 성공한 build/run은 `성공`, 일부만 확인한 경우는 `부분 성공`으로 둔다.
- capture/result는 `미확인`, `후보`, `확보`, `보류`, `제외` 기준을 따른다.
