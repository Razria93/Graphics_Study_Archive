# Documentation Policy

이 문서는 Graphics Study Archive의 문서 정본 위치와 작성 원칙을 정의한다.

## 원칙

- 문서 정본은 산출물 축 폴더에 둔다.
- `Docs/Part*` 문서는 정본으로 사용하지 않는다.
- 기존 Part 문서는 `Docs/99_Legacy/PartDocs`에서 전환기 참고 자료로만 읽는다.
- 같은 내용을 여러 위치에 원문 복사하지 않는다.
- 상세 원문은 정본 위치에 두고 다른 문서는 링크와 상태만 둔다.

## 정본 위치

| 산출물 | 위치 |
| --- | --- |
| 예제 설명 | `Docs/01_Examples/` |
| graphics 개념 | `Docs/02_Topics/` |
| build/run/capture 검증 | `Docs/03_Verification/` |
| demo evidence | `Docs/04_Demos/` |
| Issue/PR 작업 기록 | `Docs/05_WorkLogs/` |
| public subset 판단 | `Docs/06_Publication/` |
| 정책 | `Docs/07_Policies/` |
| 도구 문서 | `Docs/98_Tools/` |
| import/history | `Docs/99_Legacy/` |

## 작성 기준

- 평서형 현재형을 사용한다.
- 존댓말, 대화체, 감상문체를 사용하지 않는다.
- raw/reference 문서는 필요한 부분만 읽고 직접 이해한 설명으로 재작성한다.
- 직접 확인하지 않은 build/run/capture 상태는 `미확인`으로 기록한다.
