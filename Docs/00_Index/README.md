# Docs Index

이 폴더는 Graphics Study Archive 문서의 첫 진입점이다. 각 map 문서는 최신 상태를 복제하지 않고, 산출물별 정본 위치로 이동하는 라우팅 역할만 맡는다.

## 책임

- 세부 설명과 최신 상태를 반복하지 않고 정본 문서로 연결한다.
- Part/Chapter 기준이 아니라 산출물 축 기준으로 문서 위치를 안내한다.
- build/run, capture/result, publication 판단의 최신 상태는 각 정본 문서에 둔다.
- 오래된 import 기록과 현재 정본 문서를 구분한다.

## 먼저 볼 문서

| 문서 | 목적 |

| [Verification Map](verification-map.md) | build/run/capture/known issue 기록 위치 확인 |
| [Demo Map](demo-map.md) | capture/result와 demo 계획 위치 확인 |
| [WorkLog Map](worklog-map.md) | Work Unit 요약과 Issue/PR 연결 방식 확인 |
| [Publication Map](publication-map.md) | private archive와 public subset 후보 판단 위치 확인 |

## GitHub 게시 후보

- [GitHub Bodies](../07_GitHub/README.md)는 Issue, PR, comment 게시 후보 정본이다.
- [Publication Map](publication-map.md)은 public subset 공개 가능성 판단 위치다.
- GitHub 게시 후보와 public subset 판단은 서로 다른 책임이다.
