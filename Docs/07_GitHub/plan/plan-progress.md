## Graphics Study 진행 요약

Graphics Study Archive의 Part/Chapter 진행 상태를 누적 기록한다. 상세 내용은 각 정본 문서와 Chapter PR에서 확인한다.

### Phase 1. 문서 산출물 축 정리

### Phase 2-1. Part1 Chapter01-02 문서화 workflow 검증

### Phase 2-2. Part1 pilot 게시 모델 정리
