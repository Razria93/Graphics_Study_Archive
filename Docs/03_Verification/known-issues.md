# Known Issues

## 기록 기준

- 실패 또는 부분 성공 상태는 삭제하지 않고 원인과 follow-up을 남긴다.
- 해결된 항목은 제거하지 않고 해결 상태와 관련 WorkLog를 연결한다.
- 개인 환경 문제는 필요한 범위만 요약하고 민감 정보는 local에 둔다.
