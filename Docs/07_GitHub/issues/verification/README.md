# Verification Issues

이 폴더는 Verification Issue 정본을 둔다.

## 파일명 규칙

- `verification_<slug>.md`

## 생성 기준

- build/run 실패, 환경 이슈, 미확인 묶음이 별도 추적 대상일 때 생성한다.

## 작성 기준

- 첫 H1을 title source로 유지한다.
- build/run/capture 기준과 제한 사항을 분리해 기록한다.
- screenshot은 GitHub absolute URL을 사용한다.
- 최신 근거는 `Docs/02_Verification` 정본으로 연결한다.
