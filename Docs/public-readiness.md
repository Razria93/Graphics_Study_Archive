# Public 공개 준비 기준

이 문서는 private archive를 정리하면서 나중에 별도 public repo로 옮길 수 있는 후보와 제외 대상을 구분하기 위한 운영 기준입니다.

현재 단계에서는 public repo를 만들거나 미리 구성하지 않습니다. 먼저 private repo를 archive/study repo로 안정화한 뒤, 공개 가능한 subset을 추려 별도 public repo 또는 공개용 구조로 한 번에 설계합니다.

## 현재 방침

- 이 저장소는 private archive/study repo로 운영합니다.
- 강의 코드나 강의 자료를 직접 포함하지 않은 scaffold 문서 구조는 비교적 안전한 편으로 봅니다.
- 이후 Part 예제 코드, 강의 기반 구현물, 캡처, asset, 상세 노트가 추가되는 시점부터는 라이선스와 저작권 리스크를 별도로 검토합니다.
- public repo는 지금 만들지 않고, private repo 구성과 검증 기록이 정리된 뒤 공개 가능한 subset만 추려 구성합니다.
- 공개 가능성이 있는 파일과 폴더는 이 문서 또는 각 README의 상태 표에서 `public 후보`, `private 전용`, `검토 필요`, `제외` 중 하나로 표시합니다.

## Public 후보

다음 항목은 권리 문제가 명확하고 직접 작성 또는 직접 생성한 경우 public 후보로 검토할 수 있습니다.

- 직접 작성한 portfolio 설명
- 학습 회고와 구현 과정 요약
- 독자적으로 재구현한 코드
- 일반적인 graphics 개념 정리
- 직접 만든 실행 결과 이미지와 영상
- 라이선스가 명확한 외부 asset을 사용한 산출물
- 강의 고유 커리큘럼을 그대로 재현하지 않는 독립적인 demo 설명

## Public 제외 또는 주의 대상

다음 항목은 public repo에 포함하지 않거나, 포함 전 별도 검토가 필요합니다.

- 강의 원문 코드
- 강의 원본 영상, 슬라이드, 퀴즈, 정답
- 유료 자료 또는 유료 콘텐츠를 재배포하는 형태의 파일
- 강의 화면 캡처, 자료 이미지, 문제와 해설 전문
- 특정 강의의 비공개 커리큘럼이나 고유 구조를 과도하게 재현한 문서
- 출처나 라이선스가 불명확한 외부 asset
- private-only 개인 메모, 계정, 환경 정보, 절대 경로, 제출 대상별 기록

## 공개 전 체크리스트

public으로 옮기기 전 파일 또는 폴더 단위로 다음 항목을 확인합니다.

| 항목 | 확인 내용 | 상태 |
| --- | --- | --- |
| 원문 코드 | 강의, 책, 유료 자료의 원문 코드가 포함되어 있지 않은가 | 미확인 |
| 자료 캡처 | 강의 자료, 강의 화면, 슬라이드 이미지, 유료 자료 캡처가 포함되어 있지 않은가 | 미확인 |
| 유료 콘텐츠 | 유료 콘텐츠를 재배포하거나 대체할 수 있는 수준의 내용이 아닌가 | 미확인 |
| 커리큘럼 재현 | README나 노트가 특정 강의의 비공개 목차와 문제 흐름을 과도하게 재현하지 않는가 | 미확인 |
| 외부 asset | texture, model, image, audio, video의 출처와 라이선스가 명확한가 | 미확인 |
| private-only 정보 | 개인 경로, 계정, 로컬 환경, 제출 기록, 비공개 메모가 제거되어 있는가 | 미확인 |
| 빌드 검증 | 공개 후보 코드가 독립적으로 빌드 또는 실행 검증되었는가 | 미확인 |
| 출처 표기 | 참고 자료와 외부 asset의 출처가 필요한 범위에서 기록되어 있는가 | 미확인 |

## 상태 표시 방법

각 Part 또는 예제 README에 public 공개 가능성을 기록할 때는 다음 값을 사용합니다. raw에서 private archive로 가져올 수 있는지는 [archive-import-candidates.md](archive-import-candidates.md)의 `Import status`로 별도 관리합니다.

| 값 | 의미 |
| --- | --- |
| private 전용 | private archive 안에서만 보관합니다. |
| public 후보 | 직접 작성 또는 직접 생성한 산출물로 보이며, 공개 전 체크리스트 검토 대상입니다. |
| 검토 필요 | 강의 기반 구현, 외부 asset, 캡처, 출처가 섞여 있어 추가 확인이 필요합니다. |
| 제외 | public repo에 옮기지 않습니다. |

## Local-only 메모

구체적인 비공개 자료 목록, 개인 검토 메모, 제출 대상별 판단 기록은 git에 올리지 않습니다. 필요한 경우 다음 ignored 경로에 둡니다.

- `local/`
- `private-notes/`
- `copyright-review.local.md`
- `public-readiness.local.md`
- `*.local.md`

공유되어야 하는 운영 기준과 체크리스트는 이 문서처럼 tracked 문서로 남기고, 민감하거나 개인적인 판단 근거는 local-only 문서로 분리합니다.
