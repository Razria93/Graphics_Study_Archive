# Repo Internals Guidelines

## 적용 범위

이 규칙은 `Docs/_repo/` 아래 문서에 적용한다.

## 책임

- 이 폴더는 agent 진입점과 최소 내부 안내만 둔다.
- 정책 원문은 `Docs/07_Policies/`에 둔다.
- 도구 문서는 `Docs/98_Tools/`에 둔다.
- import/history 문서는 `Docs/99_Legacy/`에 둔다.

## 금지사항

- 새 documentation policy를 `_repo` 아래에 추가하지 않는다.
- import phase 기록을 `_repo` 아래에 다시 만들지 않는다.
- 예제 설명, Topic, Verification, Demo, WorkLog, Publication 정본을 `_repo` 아래에 두지 않는다.
