# Legacy Part Docs

이 폴더는 과거 `Docs/Part*` 구조에서 작성된 Part/Example 문서 snapshot을 보관한다. 현재 예제 README 정본은 코드 폴더의 `README.md`이며, 최신 Topic, Verification, Demo, Publication 판단은 현재 Docs 축을 기준으로 한다.

## 현재 정본 위치

| 목적 | 현재 정본 |
| --- | --- |
| 예제 README | 각 루트 코드 폴더 아래 `README.md` |
| Topic 문서 | `Docs/01_Topics/` |
| Build/run/capture 검증 | `Docs/02_Verification/` |
| Demo capture/result 계획 | `Docs/03_Demos/` |
| Work Unit 진행 기록 | `Docs/04_WorkLogs/` |
| Publication 후보 판단 | `Docs/05_Publication/` |
| 운영 정책 | `Docs/06_Policies/` |
| GitHub Issue/PR 초안 | `Docs/07_GitHub/` |

## 사용 기준

- 이 폴더의 문서는 최신 정본이 아니라 legacy snapshot이다.
- build/run/capture 상태는 과거 기록으로만 읽는다.
- 문서 내용을 새 산출물로 옮길 때는 원문 복사가 아니라 현재 코드와 raw/reference를 다시 확인한 뒤 재작성한다.
- stale path나 깨진 문구를 발견해도 본문 의미를 임의로 바꾸지 않는다.
