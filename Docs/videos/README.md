# Videos

영상은 짧고 설명적인 이름을 사용합니다. 파일이 크면 Git LFS 또는 외부 링크를 검토합니다.

예시:

- `Docs/videos/Part4/part4_particle_system.mp4`
- `Docs/videos/Portfolio_RayTracer/portfolio_raytracer_overview.mp4`

## 공개 전 확인

- 강의 화면, 강의 음성, 슬라이드, 유료 자료가 포함된 영상은 public repo로 옮기지 않습니다.
- 직접 녹화한 실행 영상이라도 외부 asset의 출처와 라이선스가 불명확하면 `검토 필요`로 둡니다.
- 큰 파일은 Git LFS 또는 외부 링크를 검토하되, public 공개 전 [../public-readiness.md](../public-readiness.md)의 체크리스트를 먼저 확인합니다.
