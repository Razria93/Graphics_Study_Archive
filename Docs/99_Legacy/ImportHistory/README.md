# Import History

이 폴더는 raw/reference repo에서 Graphics Study Archive로 예제, project, shader, asset을 선별 반영하던 과거 import 기준과 기록을 보관한다.

현재 active 작업은 import가 아니라 documentation/refactor 정리 단계다. 이 폴더의 문서는 import 당시 판단 근거와 절차를 확인할 때만 사용한다.

2. [Import Workflow](02_ImportWorkflow.md)
3. [Import Checklist](03_ImportChecklist.md)
4. [Import Verification](04_ImportVerification.md)

## 기록 문서

- [Manifests](Manifests/): Part별 import 당시 포함/제외 판단 기록

## 기준

- 최신 build/run/capture 상태의 기준 문서는 `Docs/02_Verification/build-run-matrix.md`다.
- import manifest는 import 당시 판단 기록이며 최신 검증 상태의 기준 문서가 아니다.
- PR 초안과 원문 사본은 tracked Docs가 아니라 `local/` 계열에서 관리했던 자료로 본다.
- 현재 작업 흐름은 `Docs/06_Policies/work-unit-workflow-policy.md`와 `Docs/00_Index/workflow-map.md`를 기준으로 한다.
