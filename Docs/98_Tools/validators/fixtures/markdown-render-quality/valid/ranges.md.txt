`Step4~13: 2026-07-30~31`은 code span이라 검사하지 않는다.

Step4\~13과 2026-07-30\~31은 escaped tilde라 검사하지 않는다.

~~폐기된 표현~~은 의도한 취소선이다.

~이 표현~도 의도한 단일-tilde 취소선이다.

Step4~13처럼 한 줄에 숫자 범위가 하나뿐이면 다른 단일 tilde와 짝을 이루지 않는다.

[범위가 포함된 URL](https://example.com/Step4~13/2026-07-30~31)은 link destination이라 검사하지 않는다.

<https://example.com/Step4~13/2026-07-30~31>도 autolink라 검사하지 않는다.
