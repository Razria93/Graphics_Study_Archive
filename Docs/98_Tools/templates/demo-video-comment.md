## 작성 기준

- 댓글 하나는 하나의 독립 설명 축만 다룬다.
- 제목과 설명 없이 attachment만 게시하지 않는다.
- 기술 검수와 사용자 시각 검수를 통과한 selected video만 사용한다.
- Selected video를 Demo Issue 전용 댓글에 한 번만 첨부한다.
- 같은 목적과 설명 축의 video 개선은 기존 댓글을 수정한다.
- 다른 조작, 비교 기준 또는 구현 결과는 새 댓글로 추가한다.
- 잘못된 게시, 중복 또는 공개 위험이 아닌 경우 기존 댓글을 삭제하지 않는다.
- 게시 전에는 attachment placeholder와 `local/` 경로를 원격 댓글에 넣지 않는다.
- 게시 후 comment permalink와 attachment URL을 video registry에 함께 기록한다.
