# Videos

이 폴더는 게시된 video reference와 video asset 운영 안내를 둔다. Raw, attempt와 selected video는 `local/`에 두고 published video는 GitHub Demo Issue 전용 댓글 attachment를 기본값으로 사용한다.

## 기준

- MP4, MOV와 WEBM binary를 일반 Git history에 추가하지 않는 것을 기본값으로 한다.
- Git tracked video와 Git LFS는 별도 Publication 판단과 사용자 승인이 있는 예외로만 사용한다.
- 조작, animation, simulation처럼 screenshot만으로 설명이 부족한 항목을 우선한다.
- 강의 영상, 강의 화면 녹화, 유료 자료 기반 영상은 제외한다.
- Published video는 Demo Issue 전용 댓글에 한 번 첨부하고 PR에서 필요하면 comment permalink를 연결한다.
- 상세 Demo는 핵심 screenshot과 텍스트 설명을 유지하고 실제 Demo Issue로 연결한다.
