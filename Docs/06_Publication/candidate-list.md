# Candidate List

이 문서는 public subset 후보를 기록한다. 후보는 공개 확정이 아니라 공개 전 체크리스트 대상이다.

| 후보 | 연결 문서 | 후보 이유 | 상태 | 비고 |
| --- | --- | --- | --- | --- |
| Graphics Study README 설명 | `Docs/00_Index`, `Docs/05_WorkLogs` | 직접 작성한 학습/포트폴리오 설명으로 재작성 가능 | 검토 필요 | public repo 구성 시 재작성 |
| Example 최소 설명 | `Docs/01_Examples` | 예제가 보여주는 개념을 짧게 설명 가능 | 검토 필요 | 강의 구조 복제 여부 확인 필요 |
| Topic 개념 설명 | `Docs/02_Topics` | 일반 graphics concept 설명으로 재작성 가능 | public 후보 | 코드/강의 표현 복제 금지 |
| Build/run 검증 요약 | `Docs/03_Verification` | 직접 확인한 결과는 포트폴리오 신뢰 근거가 됨 | 검토 필요 | 미확인 항목은 그대로 공개하지 않음 |
| Demo capture/video | `Docs/04_Demos`, `Docs/_assets` | 직접 실행 결과 evidence로 활용 가능 | 검토 필요 | 권리/출처/민감 정보 확인 필요 |
| Work Unit summary | `Docs/05_WorkLogs` | 작업 과정과 결과 요약으로 활용 가능 | 검토 필요 | GitHub 본문은 local에서 별도 작성 |

## 갱신 기준

- 후보가 공개 가능하다고 판단되면 근거 문서와 체크리스트 결과를 연결한다.
- 후보가 부적합하면 `private-only.md` 또는 `excluded-material.md`로 옮긴다.
- public repo로 옮길 때는 private archive 문서를 그대로 복사하지 않고 공개용 문장으로 재작성한다.
