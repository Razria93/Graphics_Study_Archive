# Work Unit Issues

이 폴더는 Work Unit Issue 정본을 둔다.

## 파일명 규칙

- `work-unit_<slug>.md`

## 생성 기준

- Progress와 Chapter PR만으로 추적하기 어려운 독립 Work Unit이 있을 때 생성한다.

## 작성 기준

- 첫 H1을 title source로 유지한다.
- `## 요약`, `## 목표`, `## 범위`, `## 핵심 작업`, `## 검증 기준`, `## Demo/Capture 필요 여부`, `## 완료 조건`, `## 관련 문서`, `## 제외 범위` 순서를 사용한다.
- source docs 원문 복제 대신 요약과 링크만 둔다.
