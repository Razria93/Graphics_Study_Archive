# Work Contract

이 template은 작업 시작 시 work profile, 범위, 필수 산출물과 종료 조건을 고정하는 local 계획 또는 WorkLog 입력용 manifest다. 상세 정책은 [Work Profile Policy](../../06_Policies/work-profile-policy.md)를 따른다.

## 분류

- Work type: Graphics / Maintenance
- Work Unit: 연결된 Work Unit / 없음
- Closes Work Unit: Yes / No
- Progress impact: Required / Not required / Pending

## 산출물 판정

선택한 profile의 모든 산출물을 `Created`, `Updated`, `Linked`, `N/A` 중 하나로 판정한다. `N/A`에는 이유를 기록한다.

| 산출물 | 판정 | 대상 또는 근거 |
| --- | --- | --- |
| profile에서 요구한 산출물 | Created / Updated / Linked / N/A | 경로, 연결 또는 제외 이유 |
