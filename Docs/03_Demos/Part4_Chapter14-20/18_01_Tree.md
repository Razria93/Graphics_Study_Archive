# Chapter18 Ex1801 Tree Demo

## 목적

Imported foliage mesh를 trunk/branch와 leaves mesh group으로 분리하고, mesh constant의 trunk/leaf wind parameter를 vertex shader 변형에 연결해 tree scene을 표시한다.

## 책임 범위

- `Ex1801_Tree`의 foliage mesh group 구성, wind parameter와 standard model render path를 설명한다.
- Build/run/capture 사실은 [Verification](../../02_Verification/Part4_Chapter14-20/verification-index.md)으로 위임한다.
- public 후보 판단은 [Publication Candidate List](../../05_Publication/candidate-list.md)로 위임한다.

## 결과 미리보기

Tracked storyboard는 없다. 2026-08-07 Debug x64 smoke에서 tree scene local candidate를 확인한다.

## 입력과 출력

| 구분 | 내용 |
| --- | --- |
| 입력 | command argument `1801`, imported foliage FBX mesh group, foliage material texture, `windTrunk`, `windLeaves`와 `globalTime` |
| 출력 | trunk/branch와 leaves를 분리해 렌더링하는 tree scene local candidate |

## 구현 흐름

1. Foliage FBX에서 mesh를 읽고 leaves에 두 mesh, trunk와 branches에 세 mesh를 각각 할당한다.
2. Leaves와 trunk model에 material factor와 world transform을 설정하고 scene list에 등록한다.
3. Leaves에는 trunk와 leaf wind parameter를 모두 설정하고, trunk에는 trunk wind만 설정한다.
4. UI의 `WindTrunk` 값은 leaves와 trunk의 trunk wind parameter를 함께 갱신한다. `WindLeaves`는 leaves parameter를 갱신한다.
5. `BasicVS`가 `windTrunk`과 `globalTime`으로 branch vertex를 회전시키고, `windLeaves`와 normal/UV 기반 wind velocity로 leaf vertex displacement를 계산한다.
6. 기본 model render path가 각 mesh group을 material과 함께 렌더링한다.

## 시각 결과

이 예제의 visual evidence는 imported foliage mesh를 trunk/branch와 leaves로 구성한 tree scene이다. 현재 정본에는 local candidate 상태만 기록하며 tracked PNG 또는 storyboard가 있다고 주장하지 않는다.

## 구현 범위와 한계

- Wind deformation은 vertex shader의 procedural transform이며 branch physics, leaf collision 또는 foliage simulation을 수행하지 않는다.
- `WindTrunk`은 leaves와 trunk에 함께 적용하고 `WindLeaves`는 leaves에만 적용한다.
- Local candidate와 raw capture는 Git에 추가하지 않는다.
- Foliage FBX, texture와 HDRI 원본 asset은 첨부하거나 직접 링크하지 않는다. 이 문서는 rendered/local evidence 정책만 기록한다.
