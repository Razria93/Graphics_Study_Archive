# GitHub Comments

이 폴더는 GitHub comment body 후보를 둔다.

## 유형

- Progress Issue 누적 진행 댓글
- Chapter/Bundle 완료 댓글
- PR review 대응 댓글

## 기준

- 댓글은 Docs 정본을 복제하지 않고 진행 상태, 검증 결과, 링크만 요약한다.
- 누적 진행 댓글은 Progress Issue 당 1개를 유지하고 갱신 방식으로 운영한다.
- 리뷰 대응 댓글은 짧은 고정 형식을 사용한다.
- 원격 댓글 게시와 수정은 사용자 승인 후에만 진행한다.

Chapter/Bundle 완료 댓글 템플릿은 `../../98_Tools/templates/work-unit-completion-comment.md`를 사용한다.
