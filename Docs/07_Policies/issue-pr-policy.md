# Issue And PR Policy

이 문서는 GitHub Issue와 PR 운영 기준을 정의한다.

## Issue 책임

Issue는 작업 범위, 검증 항목, demo 필요 여부, 완료 조건을 추적한다. Docs 원문을 복제하지 않고 정본 문서 링크와 요약을 둔다.

## PR 책임

PR은 변경 범위, 검증 결과, demo evidence, known issue, follow-up을 요약한다. PR 본문 초안은 `local/github/draft`에서 작성한다.

## WorkLog 책임

Issue/PR 작업 과정과 마감 기록은 `Docs/05_WorkLogs`에 둔다. WorkLog는 예제 설명, Topic, Verification, Demo의 정본을 대체하지 않는다.

## 운영 기준

- Issue/PR 생성은 사용자가 명시적으로 요청한 경우에만 진행한다.
- 게시 전 본문은 local에서 검토한다.
- 게시 후 필요한 사본은 local snapshot에 둔다.
- merge 후 최종 상태는 각 정본 문서에 반영한다.
