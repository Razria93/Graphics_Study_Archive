# Captures

캡처는 portfolio archive 이름 규칙에 맞춰 저장합니다.

예시:

- `Docs/captures/Part1/part1_ray_sphere.png`
- `Docs/captures/Part2/part2_depth_buffer.png`
- `Docs/captures/Part3/part3_pbr_models.png`
- `Docs/captures/Part4/part4_compute_blur.png`
- `Docs/captures/Portfolio_RayTracer/portfolio_raytracer_final.png`

## 공개 전 확인

- 강의 화면, 슬라이드, 유료 자료, 문제/해설 캡처를 포함하지 않습니다.
- 직접 실행한 결과물이라도 외부 asset의 출처와 라이선스가 불명확하면 public 후보로 표시하지 않습니다.
- public 공개 후보는 [../public-readiness.md](../public-readiness.md)의 체크리스트를 먼저 확인합니다.
