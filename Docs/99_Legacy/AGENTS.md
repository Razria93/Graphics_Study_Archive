# Legacy Guidelines

## 적용 범위

이 규칙은 `Docs/99_Legacy/` 아래 문서에 적용한다.

## 책임

- Legacy 문서는 과거 기록, 이전 구조, import 당시 판단을 보존한다.
- Legacy 문서를 현재 정본처럼 갱신하지 않는다.
- 현재 정본 위치가 다른 내용은 해당 문서로 링크한다.
- GitHub draft, 개인 메모, raw 검토 원문은 tracked Docs에 두지 않는다.
- `PartDocs/` 전체를 최신 구조에 맞춰 대량 수정하지 않는다.

## 현재 정본 참조

- 문서 라우팅은 `Docs/00_Index/`를 기준으로 한다.
- Topic은 `Docs/01_Topics/`를 기준으로 한다.
- 검증 상태는 `Docs/02_Verification/`을 기준으로 한다.
- Demo capture/result는 `Docs/03_Demos/`를 기준으로 한다.
- Work Unit은 `Docs/04_WorkLogs/`를 기준으로 한다.
- Publication 판단은 `Docs/05_Publication/`을 기준으로 한다.
- 운영 정책은 `Docs/06_Policies/`를 기준으로 한다.
- GitHub Issue/PR 문서는 `Docs/07_GitHub/`를 기준으로 한다.

## 문체

- 한국어 평서형으로 작성한다.
- 존댓말, 대화체, 감상문체를 사용하지 않는다.
- technical keywords, folder names, API names는 영어를 유지할 수 있다.
